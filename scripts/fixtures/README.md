# Content test fixtures

These fixed samples test content-loading behavior independently of the editable portfolio in the root `content/` directory. Do not synchronize them with ordinary project edits. Assets are stubbed in each test's temporary directory; nothing here is deployed.

The four published samples intentionally appear in multiple collections: Dev 3, Design 2, Data 3. The underscore-prefixed template is ignored. The tests separately exercise publishing a new draft and hiding/restoring an existing shared project.
